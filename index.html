Copias de seguridad cifradas de El Gestor

El Gestor Backup es una herramienta privada para crear, verificar y conservar respaldos cifrados del sistema El Gestor mediante Google Drive. No es una aplicación de acceso público ni ofrece cuentas a terceros.

Qué protege

La base de datos, los archivos asociados y la versión del software necesarios para la recuperación del sistema.

Cómo utiliza Drive

Con autorización OAuth 2.0, almacena archivos de respaldo previamente cifrados en Google Drive.

Control de acceso

El titular conserva el control de la cuenta, puede revocar el permiso y mantiene la clave privada de descifrado fuera del servidor de copias.

Uso previsto

La herramienta está destinada exclusivamente al mantenimiento y recuperación de un sistema de gestión privado. No examina documentos personales ajenos al respaldo, ni accede al correo o los contactos.

La integración utiliza Google Drive como destino de almacenamiento; el acceso solicitado se limita a las operaciones necesarias para gestionar los archivos autorizados de esta aplicación.

Importante: esta página es informativa. No contiene ni permite descargar respaldos, claves, contraseñas o datos de negocio.
